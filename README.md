# 七棵菜表单

angular响应式动态表单，UI库为Nebular9

此项目开源，可以自定义重新编译

## 环境

- angular21+
- nebular9+

## 代码检查

```bash
npm run lint
```

## 构建

```bash
ng build seven-food-form
```

生产构建

```bash
ng build seven-food-form --configuration production
```

## 测试

```bash
ng serve test-app
```
