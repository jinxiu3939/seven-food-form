# 七棵菜表单

angular响应式动态表单，UI库为Nebular9

## 代码检查

```bash
npm run lint
```

## 构建

```bash
ng build seven-food-form
```

生产构建

```bash
ng build seven-food-form --configuration production
```

## 测试

```bash
ng serve test-app
```

## 发布

```bash
cd dist/seven-food-form
npm pack
npm publish
```
